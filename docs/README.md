# docs

Reference material for the Ugly Christmas Sweater implementation.

- `ugly-christmas-sweater-rules.pdf` — official rulebook (local copy).
- Source: https://boardgamegeek.com/filepage/186495/ugly-christmas-sweaters-rulebook-10
- `Gamehelpuglychristmassweaters.wiki` — source for the in-game **"How to play?"** summary. That panel is
  **not** served from this repo: BGA renders the wiki page
  https://en.doc.boardgamearena.com/Gamehelpuglychristmassweaters, which has to be created and edited on
  the BGA doc wiki while logged in. This file is the versioned copy — edit it here, then paste it there,
  so the two don't drift. BGA picks up wiki edits within about an hour.

This folder is excluded from BGA SFTP uploads but is tracked in git / pushed to GitHub.
